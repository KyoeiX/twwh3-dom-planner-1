# TWW3 Dom Planner 1

Interactive Total War: Warhammer III Domination tactical planner.

## Current prototype

- Single-page static HTML app
- Three phases: Deployment, Start, Dive
- Hoverable unit tokens with tactical notes
- Cap areas I, II, III
- Khorne vs Skaven Army #1 Ver B tactical logic

## Netlify deployment

This repo is ready for Netlify as a static site.

Recommended settings:

- Branch: `main`
- Build command: leave blank
- Publish directory: `.`

`netlify.toml` is included, so Netlify should detect the static publish setup automatically.
